# 02 · 线框探索

> 这一阶段做了 6 张低保真线框，目的是**先发散**：不追求落地、不追求一致，先把可能性铺开。

## 文件清单

| 文件 | 方向 | 一句话 |
|---|---|---|
| `wireframes.html` | 主入口（含 6 张） | design_canvas 形式并排陈列，可拖拽、可全屏、可重命名 |
| `frames/diagnostic.jsx` | 现状诊断 | 6 个红字标注当前页面痛点 |
| `frames/a-tighten.jsx` | A · 微调 | 三栏保留，顶部信息合并、参数收抽屉、画布升 4 张并排 |
| `frames/b-batch.jsx` | B · 批量 + Seed 派生 | Prompt 升顶部命令栏、Inspector 暴露 seed/cfg/steps、PSD 出口 |
| `frames/c-project.jsx` | C · 项目 / 世界观为根 | 面包屑导航、左侧世界观面板（调色板 + 风格锁）、按章节分组 |
| `frames/d-terminal.jsx` | D · 命令行 + 版本树 | 深色硬核、git 风版本树、CLI prompt、全参数可读 |
| `frames/e-split.jsx` | E · 双屏 生成 ↔ 灵感板 | 左生成右 moodboard，参考图拖拽即用 |

## 评估矩阵

| 方向 | 落地成本 | 用户上手 | 解决 IA | 解决素材库 | 解决视觉 | 推荐 |
|---|---|---|---|---|---|---|
| A | ⭐ | ⭐⭐⭐ | ⭐⭐ | ⭐ | ⭐⭐ | ✅ P0 |
| B | ⭐⭐ | ⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐ | ⭐⭐⭐ | ✅ P1 |
| C | ⭐⭐⭐ | ⭐⭐ | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐ | ✅ P2 |
| D | ⭐⭐⭐⭐ | ⭐ | ⭐⭐⭐ | ⭐⭐ | ⭐⭐⭐⭐ | 子品类 |
| E | ⭐⭐ | ⭐⭐⭐ | ⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐ | 备选 |

## 决策

采取 **A → B → C 渐进**：

1. **P0 = A**：1-2 周即可上线，风险最低
2. **P1 = B**：暴露后端已有的批量 / seed 能力，对游戏从业者价值最大
3. **P2 = C**：解决"一个项目几百张图找不回来"的本质问题
4. **D / E**：暂留作子产品或 Pro 模式选项，不进主线
