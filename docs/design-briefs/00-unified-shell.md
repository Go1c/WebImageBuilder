# 00 · 统一工作台（Unified Shell · 生图工作台 × 无限画布 合并设计）

> 本任务书交付对象是 UX 设计师。产品现状是**两个工作台、两套设计语言**：LumioImageStudio 生图工作台（浅色、三栏、Next.js，`--studio-*` token 体系）与 无限画布 canvas-app（深色、点阵网格、大字号 Hero、Tailwind/shadcn 体系）。本轮目标：**把两套风格与两套功能合并成一个产品**——一套 App Shell、一套导航、一套双主题设计语言，两个工作台一眼看上去是同一个产品的两个房间，而不是两个产品。

## 1. 产品与功能设计框架（设计前必读的现状盘点）

产品：LumioImageStudio（img.lumio.games）——面向创作者的 AI 图像生成平台。账号/余额/邀请由 Lumio 账户中心（api.lumio.games）托管，本站负责创作体验。

功能全景（均已实现，设计不新增能力，只重组表达）：

| 域 | 能力 | 现落点 |
|------|------|--------|
| A 生图工作台 | 提示词/负面提示词、参考图上传、模型选择（gpt-image-2 / 2K / 4K / gemini-3.1-flash）、张数 1–4、画幅比例 5 档、1K/2K/4K 与自定义分辨率、细节强度滑杆（≥72 触发高质量档） | 主站 `/`，左栏创作面板 |
| B 生成结果操作 | 保存到作品集（本地 IndexedDB）、在画布中打开（跨工作台桥）、分享提示词卡片（`/share/:id` 短链 + 水印 + 举报）、下载、重新生成、历史条 | 主站中央画布下方 |
| C 无限画布 | 图/文/音/视频节点，节点连接与资源引用，裁剪/拆分/超分/Inpaint/旋转/蒙版，撤销重做，ZIP 导出，画布 AI 助手，项目列表 | canvas-app `/canvas/:id` |
| D 提示词/素材体系（**三套并存，本轮必须收敛词表**） | ① 主站右栏「素材库」：官方提示词库 335 条，热门/人物/场景/风格/我的 五 tab，点击套用；② canvas `/prompts`「提示词库」：搜索/标签/收藏/分享卡片；③ canvas `/assets`「我的素材」：本地增删改、导入导出 zip | 三处入口、两套数据源（admin 动态库 + 本地库） |
| E 用户与商业化 | Lumio 账号登录、额度四来源（匿名 3 次 / 登录 3 次 / 邀请奖励 / 付费余额）、次数 pill + 美元余额 pill、邀请有礼面板、全站已生成计数 | 主站顶栏 |
| F 视频创作台 | 预留（canvas-app `/video`，未上线） | 只能按「即将上线」表达 |
| G 登录与访客动线 | Lumio 账号登录浮层（auth 面板，token handoff）、未登录匿名态（免费 3 次）、被邀请者落地（`?invite=码` 领取）、教程浮层面板 | 主站顶栏浮层（不是独立页面） |
| H 分享落地页 | `/share/:id` 访客屏：水印保护图、复制提示词、下载、举报、已失效/已下架态 | 独立公开页，产品的对外门面 |
| I 管理后台 | `/admin` 十模块（用户/素材/邀请/分享审核/错误/公告/成本/安全/审计） | **本轮范围外**，但素材库分类与公告数据由它供给 |

**导航真相（屏 A 决策的事实基础）**：主站顶栏的「探索 / 作品集」并非独立页面，而是右栏素材库 tab 的两个状态（热门 / 我的）；「教程」是浮层面板。canvas 端另有 `/home` 首页、`/config` 配置页、404 页，以及 **`/image` 一套与主站重复实现的生图工作台**——合并时必须对它做收编决策。

现状问题（合并的动因）：两套顶栏导航互不相认（主站：探索/作品集/教程/无限画布；canvas：无限画布/我的画布/生图工作台/视频创作台/提示词库/我的素材/配置）；**生图工作台存在两套重复实现**（主站 `/` 与 canvas `/image`）；主题割裂（主站默认浅色、canvas 默认深色，跨页跳转像换了产品）；「素材库/提示词库/我的素材/作品集」四个词指三种东西；管理后台已有「营销公告」模块但**前端没有任何展示位**；canvas 落地页的 Hero 叙事（生成、连接、重组 → 连续推演；沉淀每一次好结果）是全产品最好的价值表达，却只在 canvas 里。

## 2. 设计系统硬约束（Design Tokens）

融合后的单一体系，浅深双主题各自完整，任何新屏不得引入体系外颜色/圆角：

| 类别 | Token | 值 |
|------|-------|-----|
| 品牌三色 | `--lumio-violet` / `--lumio-teal` / `--lumio-orange` | `#8b78f5`（生成身份）/ `#2cd4be`（画布身份）/ `#f3a63a`（强调/标注） |
| 强调 | `--studio-purple`（生成 CTA）/ `--studio-green`（金额/成功） | `#7f22fe` / `#00bc7d` |
| 浅色背景 | `--studio-bg` / `--studio-surface` / `--studio-panel` | `#fafafa` / `#ffffff` / `rgba(255,255,255,.4)` |
| 深色主题 | `[data-theme="dark"]` 变量重映射 | 深色不是浅色反相，基调取自 canvas 现深色：近黑底 + 点阵网格纹理 |
| 文字 | `--studio-text` / `--studio-copy` / `--studio-muted` | `#171717` / `#404040` / `#737373` |
| 圆角 | `--ui-radius-control` / `--ui-radius-card` | 12px / 16px |
| 字体 | Inter + Noto Sans SC 系统栈 | — |

**风格合并规则（本任务书核心）**：
1. **浅色 = Studio 气质**：白底卡片、半透明面板、克制阴影，承担高频生产（生图面板、素材库、后台数据）。
2. **深色 = Canvas 气质**：近黑点阵网格底、超大号标题排版、`--lumio-orange` 下划线/高亮标注（canvas Hero 的「无限画布」下划线与「图片、文字与图形」高亮块是既有签名，保留为设计语言）、`--lumio-teal` 作画布域强调。
3. 双主题是**同一套组件换 token**，不是两套组件——每个组件规格给浅/深两态；用户切主题（顶栏太阳/月亮开关 + `?theme=` + localStorage）后两个工作台同步。
4. 域身份色：生成域一律 violet/purple 系，画布域一律 teal 系（现「在画布中打开」按钮的青绿已是先例），金额一律 green，跨域跳转靠色彩即可辨向。

## 3. 要设计的屏

### 屏 A · 统一 App Shell 与全局导航（其余各屏的公共依赖，先定稿）

- 一条顶栏收编两套导航。建议 IA（设计稿定稿并给理由）：**探索（生图）· 无限画布 · 视频创作台（置灰即将上线）· 作品集 · 提示词库 · 教程** + 右侧账户区（次数 pill / 余额 pill / 邀请有礼 / 账号菜单：配置、主题切换、退出、版本号）。canvas 现「我的画布」收进无限画布落点内的项目列表；「我的素材」并入提示词库的「我的」视角（见屏 D）。
- **IA 决策必答**：①「探索/作品集」现状只是素材库 tab 状态，合并后是升级为真页面（可深链）还是保留为面板状态——定稿其一并给理由；② canvas `/image` 重复生图工作台的收编方案（建议：退役，统一回主站生图工作台，画布内保留节点级快捷生成）；③ canvas `/home`、`/config` 的去留（建议：`/config` 收进账号菜单，`/home` 由屏 C 落地页替代）。
- 「全站已生成 N 次」社会证明 pill 保留在 Logo 侧，两工作台一致；给出其加载态规格（现网「-- 次」占位横线属假数据反例）。
- **公告横幅展示位**：管理后台已有营销公告模块（含排期），前端缺展示位——本屏定稿横幅位置（建议顶栏下通栏）、浅/深两态、可关闭规则与多条排队策略。
- 顶栏浅/深两态规格；当前页高亮、Beta 徽标规格。
- Shell 级公共页一并交付：404（canvas 现有 not-found 收编为全站统一 404）、整页加载骨架。
- 现主站顶栏「探索/作品集/教程/无限画布」在窄宽度下发生纵向折字（截图可见），本轮一并修正：给出 1280 / 1024 / 768 / 375 四档顶栏降级方案。

### 屏 B · 生图工作台（浅深双态）

- 保持现三栏骨架（创作面板 340px | 画布 | 素材库 320px），但按合并 token 重制视觉；**深色态是新增交付**（现仅浅色成熟）。
- 创作面板控件全集（见 §1.A）逐个给浅/深规格；细节强度滑杆两端「柔和/锐利」语义保留。
- 生成结果操作条六操作（保存到作品集/在画布中打开/分享提示词卡片/删除/下载/重新生成）：「在画布中打开」用 teal 表达跨域去向；生成中/成功/失败三态与历史条一并出稿。
- 生成预览空态借用 canvas 叙事升级：不再是灰底「生成预览」四个字，给一句价值文案 + 示例提示词引导（与屏 E Hero 同语气）。

### 屏 C · 无限画布（落地页 + 编辑器 Shell）

- **落地页**保留现 Hero 骨架（大标题 / 标注式副文案 / 开始使用 + 打开画布双 CTA / 「沉淀每一次好结果」提示词库导流区），但顶栏替换为屏 A 统一 Shell，并补浅色态（现仅深色）。
- **编辑器**只做 Shell 级统一：顶栏、面板 chrome、节点选中色（teal）、AI 助手面板样式对齐 token；节点交互本身不重设计。
- 「在画布中打开」跨域动线：从生图结果 → 新建/追加到画布项目的衔接页面或过渡态，明确用户此刻在哪、图去了哪。

### 屏 D · 提示词库 / 素材统一（词表收敛屏）

- **词表定稿（设计稿必须逐字执行）**：官方内容一律「提示词库」（分类：热门/人物/场景/风格）；用户本地收藏与上传一律「我的素材」，作为提示词库内的「我的」tab（含原 canvas assets 的导入导出/编辑能力）；生成成品一律「作品集」。「素材库」一词退役，不再出现。
- 主站右栏 = 提示词库的**嵌入态**（搜索 + 五 tab + 卡片流 + 点击套用 + 总数徽标）；`/prompts` 独立页 = **完整态**（多标签过滤、详情弹层、收藏、分享卡片）。两态卡片 anatomy 必须同源：缩略图 + 标题 + `#序号 · 分类`。
- 卡片点击「套用」的反馈（提示词落入输入框的确认表达）与「加入我的素材」的轻反馈。

### 屏 E · 账户、额度、登录与邀请（含未登录全动线）

- 次数 pill（橙黄系）+ 余额 pill（green）+ 邀请有礼入口的浅/深两态；点开的邀请面板（邀请码、已邀人数、已得奖励、复制链接、去 Lumio 账户中心的外链边界说明）。
- **登录浮层（auth 面板）**：Lumio 账号登录的浮层设计（含 token 交接的加载/失败态）；未登录顶栏态（「登录」按钮替代邮箱+退出）；匿名可用 3 次的诚实表达与登录引导时机（额度将尽时提示，不拦生成）。
- **被邀请者落地动线**：好友通过 `?invite=码` 进站 → 领取确认表达（领到什么、登录前后差异）→ 与邀请面板的闭环。
- **教程浮层面板**：现顶栏「教程」是浮层不是页面——给出浮层规格，或在屏 A 的 IA 决策里升级为页面。
- 额度四来源（匿名/登录/邀请/付费）在扣费时的可见性：生成按钮附近「本次消耗 1 次 · 剩 N 次」级别的诚实提示；额度耗尽态（引导登录/邀请/充值三出路）。

### 屏 F · 分享落地页（`/share/:id`，对外门面）

- 访客视角的提示词卡片页：水印保护大图 + 提示词全文 + 生成参数摘要 + 作者归属；操作：复制提示词、下载图片、举报。
- 这是**未登录访客看到的第一屏**，承担拉新转化：给「我也要生成」CTA（带 `?prompt=` 预填跳生图工作台）的位置与力度。
- 状态齐全：正常 / 已失效或已下架（现有 ShareUnavailableRedirect 的体验化表达，不能是白屏跳转）/ 加载 / 举报成功后的反馈。
- 浅/深两态 + 移动端优先（分享链接多在手机打开）。

## 4. 全局交互规范（每一屏都要遵守）

1. **四态完备**：每个数据区域给 默认/空/加载/错误 四态；错误必须带重试或出路，不得画成空态（提示词库拉取失败 ≠「还没有素材」）。
2. **空态区分语义**：作品集空（引导去生成）≠ 我的素材空（引导收藏）≠ 生成预览空（价值引导）。
3. **mutation 必有反馈**：套用提示词、保存作品集、复制邀请链接、生成分享短链，成功都要有轻反馈；失败 toast 说人话。
4. **破坏性操作必确认**：删除生成结果/删除我的素材/删除画布项目，产品级确认弹窗，禁用原生 confirm。
5. **禁假 UI**：视频创作台等未上线能力只能置灰 +「即将上线」；不得出现可点无效控件与假数据（现顶栏「全站已生成 -- 次」的占位横线即是反例，给出加载态规格）。
6. **全中文人话**：不出现 `gpt-image-2-2k`、`spend_source` 等工程原文暴露在正文文案（模型选择器中的模型名除外，作为专有名词保留）。
7. **可达性**：交互控件有 focus 态、可键盘操作；弹层 Esc 可关。
8. **375px 口径**：三栏 → 单栏的折叠顺序（面板置顶、素材库收为抽屉）与画布端的移动降级说明。
9. **URL 可深链**：主题（`?theme=`）、预填提示词（`?prompt=`）、画布项目（`/canvas/:id`）、提示词库分类 tab 均可被 URL 表达。

## 5. 已锁产品决策（设计不得违反）

- 账号/支付/邀请奖励的**权威在 Lumio 账户中心**，本站只展示与跳转，不做账户管理界面。
- 生成扣费顺序 匿名 → 登录免费 → 邀请 → 付费 是后端既定逻辑，界面只如实展示来源与余量，不重开。
- 作品集与我的素材是**本地存储**（IndexedDB），设计要为「仅存在本设备」给出诚实标注，不得暗示云同步。
- 分享短链带水印与举报，是内容安全要求，卡片设计不得移除。
- 无限画布节点模型（图/文/音/视频 + 连接引用）沿现实现，本轮不动交互内核。

## 6. 交付格式

- 高保真原型（独立可运行 HTML 或 Figma）+ handoff README（Overview / 逐屏 Layout 与组件 / Interactions & Behavior / 状态清单 / 新增 token 登记）。
- 保真度：颜色/间距/圆角/字重按 §2 token 落定；每屏浅/深双态成对交付；关键路径含失败路径可走通。
- 与现网不一致处必须在 README 写明理由，不静默「优化」。
