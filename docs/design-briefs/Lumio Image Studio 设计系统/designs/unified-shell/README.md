# Handoff · 00 统一工作台（Unified Shell）

高保真可运行原型：`index.html`（`tokens.css` + `shell.css` + `screens.css` + `app.js`）。
左下角「状态演示」条为审阅工具，非产品 UI。

## Overview

一套 App Shell、一套导航、一套双主题设计语言。浅色 = Studio 气质（白底卡片、半透明面板、克制阴影）；深色 = Canvas 气质（近黑点阵网格底、橙色标注签名）。双主题为同一组件换 token（见 `tokens.css` 的 `[data-theme="dark"]` 重映射），顶栏太阳/月亮开关 + `?theme=` + localStorage 三处同步。

域身份色贯穿全站：生成 = violet/purple、画布 = teal、金额 = green。

## 屏 A · 统一顶栏（IA 定稿与理由）

导航：**探索（生图）· 无限画布 Beta · 视频创作台（置灰 · 即将上线）· 作品集 · 提示词库 · 教程（浮层）**。

三个 IA 必答题的定稿：

1. **「探索 / 作品集」升级为真页面**（`#studio` / `#portfolio` 可深链）。理由：作品集是「生成成品」的唯一容器（词表收敛后），塞在右栏 tab 里既不可分享链接也放不下管理动作（删除、导出）；探索保留为生图工作台默认页，右栏素材库 tab 状态废除。
2. **canvas `/image` 退役**，统一回主站生图工作台；画布内保留节点级快捷生成。理由：两套实现必然漂移，且额度/分享/历史都长在主站侧。
3. **`/config` 收进账号菜单**（原型内账号菜单含「偏好配置」项）；**`/home` 由屏 C 落地页替代**。canvas「我的画布」收进无限画布落点的项目列表；「我的素材」并入提示词库「我的」tab。

其他定稿：
- 「全站已生成 N 次」pill：加载中为**微光骨架条**（非「-- 次」占位横线），1.4s 后落数字；1280px 以下整体隐藏（非核心信息）。
- **公告横幅**：顶栏下通栏。浅色 amber 底 / 深色 orange-soft 底；可关闭；多条按序排队（右侧「1 / 2」计数），关闭一条显示下一条；数据来源为管理后台公告模块（见 01 号联动）。
- 404：点阵网格底 + 大数字 + 橙色下划线签名 + 回生图站 CTA，收编 canvas not-found 为全站统一。
- 响应式四档：1280（隐计数 pill、收窄导航字距）→ 1024（额度/余额 pill 只留数字、藏邀请）→ 768（藏 pill 与徽标）→ 480/375（导航横向滚动、藏品牌字）。修正现网纵向折字。

## 屏 B · 生图工作台

三栏骨架保留（340 | 1fr | 320）。深色态为新增交付：中央画布深色下叠点阵网格。

- 创作面板控件全集：提示词卡（参考图行 + 生成 FAB）、负面提示词、模型/张数、画幅 5 档 + 自定义分辨率（宽高校验文案）、细节强度滑杆（柔和/锐利语义保留，≥72 显示「已启用高质量档」）。生成 FAB 与滑杆进度改用 `--ui-generate`（域身份色）。
- 生成按钮下方常驻「本次消耗 1 次 · 剩 N 次」诚实提示；额度将尽（橙→红 pill）与耗尽态（三出路：登录 / 邀请 / 余额）见演示条。
- 结果操作六件套：保存到作品集（黑）、**在画布中打开（teal，跨域去向）**、分享提示词卡片（green 渐变）、下载 / 重新生成 / 删除（图标按钮 + tooltip）。删除走产品级确认弹窗。
- 四态：空态为价值引导（标题橙色下划线 + 示例提示词按钮，与落地页同语气）；加载态含进度条与时长预期；失败态注明「未扣除额度」+ 重试；成功态入历史条。
- 历史条：56px 缩略图，选中黑描边。

## 屏 C · 无限画布落地页

Hero 骨架保留（大标题 / 橙色下划线 + 蓝色高亮块标注副文案 / 双 CTA / 「沉淀每一次好结果」导流区），顶栏换统一 Shell，**浅色态补齐**（浅色也保留点阵网格，密度更低）。编辑器内核本轮不动。

跨域动线：「在画布中打开」→ 过渡浮层（当前图 → 画布节点示意 + 新建/追加两选项）→ toast 明确「图去了哪」。

## 屏 D · 词表收敛

全稿只出现「提示词库 / 我的素材 / 作品集」，无「素材库」。嵌入态（右栏：搜索 + 热门/人物/场景/风格/我的 + 总数徽标）与完整态（`#prompts`：多分类过滤 + 收藏 ☆）卡片同源：缩略图 + 标题 + `#序号 · 分类`。套用反馈 = 落入输入框 + toast「提示词已套用」；收藏 = ☆→★ + toast。「我的」tab 带「仅保存在本设备」标注。三种空态语义分开（作品集空引导去生成 / 我的素材空引导收藏 / 库拉取失败带重试，明确「不是没有内容」）。

## 屏 E · 账户 / 额度 / 登录 / 邀请

- 次数 pill（amber）/ 余额 pill（green）/ 邀请有礼浅深两态；邀请面板：3 KPI + 复制链接 + 账户中心外链边界说明。
- 登录浮层：token 交接加载态（spinner + 文案）与失败态（重试）；未登录顶栏 =「登录」黑 pill + 免费体验 pill。
- 被邀请者落地（`?invite=`）：领取浮层写明「登录前 3 次 / 登录后 +20」。
- 教程定稿为浮层（三步引导），不升级为页面——内容量不足以支撑页面。

## 屏 F · 分享落地页

水印保护图 + 提示词全文 + 参数摘要 + 作者归属 + 复制/下载/举报；**「我也要生成 · 免费 3 次」为最强 CTA**（violet，带 `?prompt=` 预填跳生图）。失效/下架态为体验化卡片（非白屏跳转）。移动端单列。举报走确认弹窗 + 成功 toast。

## 状态清单

顶栏计数（骨架/数字）· 公告（显示/排队/关完收起）· 额度（充足/将尽/耗尽）· 生成（空/加载/成功/失败）· 提示词库（正常/加载/错误/我的空）· 作品集（有内容/空）· 登录（未登录/交接中/失败/成功）· 分享页（正常/失效）· 404。均可在演示条触发。

## 新增 token 登记

`--ui-canvas`（画布域强调，浅 #20b9a6 / 深 #2cd4be）、`--dot-grid` / `--dot-grid-size`（点阵签名）、`--hero-ink`（Hero 大字色）。其余全部沿用现网 `--studio-*` / `--lumio-*` 值，未改浅色像素。

## 与现网不一致处（理由）

1. 生成 FAB、滑杆由黑色改 `--ui-generate` 紫——落实「生成域一律 violet」的域身份色规则。
2. 右栏「素材库」标题改「提示词库」——词表收敛硬性要求。
3. 顶栏「探索/作品集」由 tab 状态升级为页面——见 IA 必答 ①。
4. 「全站已生成 -- 次」占位横线改骨架微光——禁假 UI 条款。
