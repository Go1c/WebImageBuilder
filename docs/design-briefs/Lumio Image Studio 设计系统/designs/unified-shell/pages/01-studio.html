账户区

次数 pill（amber，将尽转红）· 余额 pill（green）· 邀请有礼（浮层）· 主题开关 · 头像点击开账号菜单（账户中心 / 偏好配置 / 切主题 / 退出 / 版本号）。未登录时此区 = 免费体验 pill + 黑色「登录」。

3
公告横幅

数据来自后台公告模块。✕ 关闭当前条→ 显示下一条（右侧 1/2 计数）；全部关完横幅收起，同一公告本设备不再出现。链接→ 深链到目标页。

4
生成按钮（violet FAB）+ 额度提示

点击开始生成：中央进加载态、FAB 置灰。下方常驻「本次消耗 1 次 · 剩 N 次」；额度耗尽时点击不发请求，toast 给三出路（登录 / 邀请 / 余额）。⌘⏎ 快捷生成。

5
参考图行

最多 3 张，48px 缩略图；＋ 上传（拖拽亦可）；悬停出 ✕ 移除。超限时 ＋ 置灰 + tooltip「最多 3 张」。

6
模型与张数

模型：gpt-image-2 / 2K / 4K / gemini-3.1-flash。未登录选 2K/4K：选项可选但选中即弹登录浮层（诚实拦截，不静默失败）。张数 1–4；多张时中央变四宫格。

7
画幅 + 自定义分辨率

5 档单选（黑底选中）。点「自定义分辨率」展开宽×高输入（256–4096、64 倍数），非法值红框 + 文案，生成按钮不禁用但点击时聚焦错误字段。

8
细节强度滑杆

0–100，两端语义「柔和 / 锐利」；≥72 显示「已启用高质量档」（violet 字），提示词自动追加「细节锐利」。进度条用生成域 violet。

9
