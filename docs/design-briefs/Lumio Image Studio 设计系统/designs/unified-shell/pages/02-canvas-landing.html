页面定位

画布域的「主页」：合并后 canvas 独立站的 /home 由本页替代，顶栏换统一 Shell。它承担两件事——向新用户讲清无限画布的价值（Hero 叙事是全产品最好的价值表达，原样保留），并把老用户一步送进编辑器。
