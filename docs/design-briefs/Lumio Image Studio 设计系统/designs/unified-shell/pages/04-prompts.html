词表定稿（逐字执行）

官方内容 = 提示词库（热门/人物/场景/风格）；用户收藏与上传 = 我的素材（本页「我的」tab，含导入/导出 ZIP、编辑、删除）；生成成品 = 作品集（P5）。「素材库」一词全站退役。

逐控件规格

1
页头 + 本地存储标注

总数与「我的素材仅保存在本设备」诚实标注常驻。

2
搜索 + 分类 chip

搜索标题/标签/提示词全文（300ms 防抖）；chip 单选，「我的」带计数徽标。tab 与搜索词写入 URL（?tab=&q=）可深链分享。「我的」tab 追加工具行：导入 ZIP / 导出 ZIP / 新建素材。

3
卡片（与嵌入态同源 anatomy）

缩略图 + 标题 + #序号 · 分类；悬停出 ☆（点击加入我的素材，★ 常显）；点卡片开详情弹层（不直接套用——完整页以浏览为主，套用是二步动作）。

4
详情弹层

大图 + 全文 + 使用次数。「✦ 用它生成」violet→ P1 ?prompt= 预填；「加入我的素材」轻反馈 toast；「复制」复制全文。Esc / 点外部关闭；弹层 URL 化（/prompts/13）可直接分享。「我的」素材的弹层多出：编辑 / 删除（确认弹窗）。
