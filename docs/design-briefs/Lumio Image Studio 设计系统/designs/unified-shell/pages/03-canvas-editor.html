1
编辑器顶栏 · 全局操作

撤销/重做：⌘Z / ⇧⌘Z，无可重做时置灰。导出 ZIP：点击打包全部节点资源与画布 JSON 下载。AI 助手：点击开关右侧面板（teal 高亮 = 开）。主题开关与全站同步。

2
项目名（行内改名）+ 自动保存

点击项目名直接编辑，失焦保存并 toast「已改名」。右侧常驻「已自动保存 · N 秒前」；保存失败时变红「保存失败 · 重试」，点击重试。

3
左工具栏 · 节点创建

选择 V / 拖动 H（或按住空格）/ 图片 I / 文本 T / 音频 / 视频（置灰「即将上线」）/ 连接线 C。选中工具后在画布点击落节点；图片节点落下即打开「上传 or 从作品集选 or 生成」三选浮层。

4
我的画布（项目抽屉）

收编自 canvas 独立页。顶栏「☰ 我的画布」点击展开；当前项目 teal 高亮；点其他项目→ 切换加载该画布（URL /canvas/:id）；「＋ 新建」建空画布并进入改名态。删除项目走产品级确认弹窗（列明节点数）。

5
节点工具条（选中时浮现）

裁剪 / 拆分 / 超分 / Inpaint / 旋转 / 蒙版：点击进入对应编辑模式，结果生成新节点并自动连线（保留推演链）。「✦ 再生成」violet（生成域）：基于上游文本节点重新生成，按钮旁标注「消耗 1 次 · 剩 N 次」。

6
节点与连接（teal = 画布域）

选中描边 teal + 光晕；两侧圆点为连接口，拖出→吸附到目标口成实线；虚线 = 引用关系。双击图片节点放大预览；右键菜单：复制 / 删除（确认弹窗）/ 保存到作品集 / 下载。

7
缩放与视图

− / ＋ 步进 10%，滚轮 + ⌘缩放、拖动平移；⛶ 适配全部节点（⇧1）。缩放值持久化到项目。

8
画布 AI 助手

对话式操作画布：生成变体、拼图、批量整理。AI 的每个动作在消息里写明消耗与去向（「消耗 1 次」「已自动连线」）。失败消息带「重试」。Esc 关闭面板。

四态

默认
如上稿：节点 + 连线 + 工具。新用户空画布见「空态」。
空画布
画布中央价值引导（同落地页语气）：「拖一张图进来，或按 I 落一个图片节点」+ 三个快捷入口：上传 / 从作品集选 / 直接生成。
加载
项目切换时画布整体骨架（点阵底 + 节点位灰块）；生成中的节点内嵌进度条（同生图工作台加载态语言）。
错误
节点生成失败：节点变红边 + 「生成没有成功 · 未扣额度 · 重试」；项目加载失败：整页错误态 + 重试 + 回「我的画布」。
